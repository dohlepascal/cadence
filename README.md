# 🕓 Cadence
A clean and minimalistic interval timer built for focus, workouts, and mindful breaks.

Cadence is designed with soft black, white, and Catppuccin-inspired pastel tones — creating a calm and distraction-free experience.  
Built by [Voit aka. Pascal Dohle](https://pascaldohle.dev), Cadence helps you find your rhythm in every routine.

---

## ✨ Features
- 🧘 Simple, elegant, and distraction-free UI  
- 🎨 Catppuccin-inspired pastel color themes  
- ⏱️ Custom interval sets for workouts, study, or focus sessions  
- 🔊 Optional sound cues for start, rest, and finish  
- 🌙 Light and dark mode support  
- 💾 Saves your favorite intervals locally  

---

## 🧩 Tech Stack
- Flutter (cross-platform)
- Dart
- Riverpod (state management)
- Shared Preferences

---

## 💡 Vision
Cadence isn’t just another timer — it’s a moment of clarity and the last timer you will ever need.  
Whether you’re training, meditating, or simply taking a break, Cadence helps you **stay in rhythm**.
